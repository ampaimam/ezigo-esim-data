Access

EndpointUse
https://ampaimam.github.io/ezigo-esim-data/ezigo-esim-plans-single-country.json Primary. Served with Cache-Control: max-age=600.
https://raw.githubusercontent.com/ampaimam/ezigo-esim-data/main/ezigo-esim-plans-single-country.json Fallback. No cache, but rate limited to 60 requests/hour per IP for unauthenticated clients.
Neither endpoint is behind bot protection. No special User-Agent or request header is required — a plain requests.get() or http.Get() works. The response is gzip-compressed (about 55 KB on the wire instead of 1.7 MB), so keep Accept-Encoding: gzip enabled.

Schema

Top level: provider, generated, currency, note, plans. Each record carries destination, plan type, allowances, throttle behaviour, validity, price, network and hotspot flag. See the repository README for the full field list.
